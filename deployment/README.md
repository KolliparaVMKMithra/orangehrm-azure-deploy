# OrangeHRM 5.8.1 — Azure VM Deployment Guide

This repository contains fully-optimized deployment scripts to provision, configure, and deploy OrangeHRM 5.8.1 on Microsoft Azure using a single Virtual Machine running a LAMP stack (Apache, PHP 8.1, MySQL 8.0).

---

## 🚀 Step 0: Pushing the Project to GitHub

Before running the deployment scripts, push your deployment files to your own GitHub repository. We have already created a `.gitignore` to protect your sensitive credentials (`azure_vm_info.json`, `db_config.json`, etc.) from being uploaded to public version control.

Open your local terminal or PowerShell in this directory (`c:\Users\DELL\Documents\orangehrm-azure-deploy\orangehrm-azure`) and run:

```bash
# 1. Initialize local Git repository
git init

# 2. Add all deployment files to tracking
git add .

# 3. Create your first commit
git commit -m "Initial commit: OrangeHRM Azure VM deployment scripts"

# 4. Create a new repository on github.com (do NOT initialize it with README or gitignore)
# 5. Link this local repository to your remote GitHub repository
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# 6. Rename local branch to main and push
git branch -M main
git push -u origin main
```

## 🛠️ Prerequisites

Before executing the deployment scripts, make sure you have installed the following requirements on your local computer:

1. **Azure CLI:** Install from [Azure CLI Documentation](https://learn.microsoft.com/en-us/cli/azure/install-azure-cli).
2. **Azure Login:** Run `az login` in your terminal and sign in with your Azure subscription.
3. **Python 3.8+:** Installed on your path.
4. **Python Dependencies:** Run `pip install paramiko` to install SSH libraries.
5. **SSH Key Pair:** The scripts use standard SSH keys to connect to the VM. Generate one if it does not exist:
   ```bash
   ssh-keygen -t rsa -b 4096 -f ~/.ssh/id_rsa
   # Press Enter for defaults (no passphrase)
   ```

## 📋 Step-by-Step Deployment

### STEP 1: Provision the Azure VM
Run the provisioning script:
```bash
python 01_provision_azure.py
```
**What it does:**
- Creates a Resource Group (`orangehrm-rg` in `eastus` by default).
- Configures Virtual Network and Subnet.
- Configures a Network Security Group (NSG) and opens ports **22 (SSH)**, **80 (HTTP)**, and **443 (HTTPS)**.
- Provisions a Static Public IP.
- Provisions an Ubuntu 22.04 VM instance.

> [!WARNING]
> **Handling "SkuNotAvailable / Capacity Restrictions" Errors:**
> Azure commonly restricts specific VM sizes (like `Standard_B2s` or `Standard_DS1_v2`) in crowded regions (like `eastus` or `centralus`) for standard/free-tier subscriptions.
> If the script fails during VM creation with a `SkuNotAvailable` error:
> 1. Open `01_provision_azure.py` in an editor.
> 2. Locate the `CONFIG` block at the top.
> 3. Modify the `"location"` (e.g., to `"westus3"`, `"swedencentral"`, or `"uksouth"` which have more capacity) and/or change the `"resource_group"` name to avoid location conflicts.
> 4. Modify the `"vm_size"` to an available size (e.g., `Standard_D2as_v5` for AMD v5 or `Standard_DS1_v2` for legacy).
> 5. Re-run `python 01_provision_azure.py`.

---

### STEP 2: Install the LAMP Stack
Once the VM is ready, install the server runtime:
```bash
python 02_install_lamp.py
```
**What it does:**
- Connects to your VM via SSH.
- Installs Apache Web Server.
- Installs PHP 8.1 and all required extensions (`pdo_mysql`, `mbstring`, `xml`, `zip`, `gd`, `curl`, `intl`, `ldap`, `soap`).
- Installs MySQL 8.0 Database Server.
- Automatically handles first-run root database configurations.
- Creates the `orangehrm_db` database and `orangehrm_user` user, configuring them to use secure native password authentication.
- Configures Apache virtual host rules and enables `mod_rewrite`.

---

### STEP 3: Upload and Deploy OrangeHRM
Package and transfer the application:
```bash
python 03_deploy_orangehrm.py
```
**What it does:**
- Zips your local OrangeHRM folder (from `C:/Users/DELL/Downloads/orangehrm-5.8.1/orangehrm-5.8.1`).
- Uploads the zip file securely to the remote VM via SFTP.
- Extracts files to the web server directory `/var/www/html/orangehrm/`.
- Correctly configures folders ownership (`www-data:www-data`) and sets permissions (`755` for web assets and `777` for required writable paths: `src/cache/`, `src/log/`, `web/uploads/`, `lib/confs/`, `lib/logs/`).
- Runs remote checks to verify database connectivity.
- Cleans up temporary files from both your local machine and the VM.

---

### STEP 4: Complete Web Installer in Browser
1. Open your browser and navigate to `http://<YOUR_VM_PUBLIC_IP>/`.
   *(You can find the public IP inside `azure_vm_info.json` generated by Step 1).*
2. The OrangeHRM Web Installer will load:
   - **Welcome:** Select **Fresh Installation**.
   - **License:** Accept the license terms.
   - **System Check:** Verify all checks are green (the script pre-configured everything!).
   - **Database Configuration:** Enter the database details saved in `installer_info.json`:
     - **Database Host:** `localhost`
     - **Database Port:** `3306`
     - **Database Name:** `orangehrm_db`
     - **Privileged DB User:** `root`
     - **Privileged DB Password:** `OrangeHRM@Azure2025!` *(or your configured password)*
     - **OrangeHRM DB User:** `orangehrm_user`
     - **OrangeHRM DB Password:** `OrangeDB@Pass2025!` *(or your configured password)*
   - **Admin Account:** Create your administrator username and password.
   - **Install:** Confirm and let the setup finish.

---

### STEP 5: (Optional) Configure HTTPS / SSL
If you have a domain name pointing to your VM's public IP address, configure Let's Encrypt SSL:
```bash
python 04_setup_ssl.py
```
It will install Certbot, configure Apache virtual hosts with your domain, obtain the SSL certificates, and configure automatic renewals.

---

### STEP 6: Run Diagnostics (Optional)
Run the health check at any time to verify system health:
```bash
python 05_health_check.py
```
It diagnoses VM power state, database connectivity, PHP extensions, and folder permissions.

## 🧹 Cleanup / Resource Deletion

If you need to delete all resources and clean up your subscription, simply run:
```bash
az group delete --name orangehrm-rg --yes
```
*(Replace `orangehrm-rg` with your actual resource group name if changed).*
